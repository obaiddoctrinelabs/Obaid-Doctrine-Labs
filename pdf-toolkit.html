Important notes

Is this toolkit free?

The tools on this page have no payment step. Your device and browser still determine how quickly large PDFs can be processed.

Can it edit existing PDF text or convert PDF to Word?

This first version can add text overlays but does not replace existing text in place. PDF-to-Word, OCR, password removal and true image compression are not included yet.

Are my files uploaded?

The processing code on this page reads files in your browser and does not send the selected PDF to an ODL server. PDF library scripts are loaded from third-party CDNs.

Always keep your original file. Check output before using it for official, legal, academic or financial submissions. Password-protected or damaged PDFs may not open.
